API v1

Hệ điều hành tình báo khách hàng

Giao diện web linh hoạt, tối ưu mobile và PWA — mỗi bản phát hành là một bản hoàn chỉnh hơn bản trước (API /v1, mở rộng module theo window.CIOS).

Meta API

GET /v1/meta — phiên bản, commit, khả năng mở rộng. Header X-App-Version, X-API-Compat.

Sức khỏe dịch vụ

GET /health và GET /health/db cho giám sát và CI.

Mobile-ready shell

Bottom nav, vùng an toàn (notch), touch tối thiểu 44px — nền cho Capacitor / React Native sau này.

Registry module

registerFeature / mountFeature trong /js/app.js để gắn thêm màn hình mà không phá vỏ ứng dụng.

Design tokens

Biến CSS tập trung trong /css/tokens.css — dễ đồng bộ theme app native.

Phiên bản động

/version.json đồng bộ từ package.json trước khi deploy (xem script trong repo).
