# CIOS Architecture – Constitutional Intelligence Operating System

## 4 Layers (liên kết trực tiếp với IAI.ONE)

1. Charter Layer (`i ai.one`) → Enforceable rules on-chain
2. Intelligence Layer (`flow.iai.one`) → Agent Swarm
3. Operating Layer (this app) → Realtime control
4. Physical/Economy Layer → Robot + Crypto

## Core Engine: Charter Enforcement Engine (CEE)

- Input: User action + Charter JSON
- Output: zk-proof compliance
- Tech: WebAssembly + Cloudflare Workers

## Data Flow

User Charter → CIOS Shell → Flow Engine → Physical/Crypto execution → On-chain log
